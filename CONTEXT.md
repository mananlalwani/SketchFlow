# SketchFlow Drawing Workspace

SketchFlow is a collaborative drawing workspace. This glossary names the project content, its local recovery copy, and the visual form presented on the canvas.

## Project content

**Project snapshot**:
A point-in-time representation of a project's title and drawing content, used to preserve one coherent version of the work for saving or recovery. It contains durable project content and excludes transient view, selection, and collaboration presence.

**Project recovery**:
Restoration of a recent local project snapshot that may contain unsaved changes after the project is opened. Recovered content remains the user's draft until they review and save it.

## Canvas

**Canvas presentation**:
The visual rendering of a project's drawing content in the current canvas view. It reflects the project's object order and visibility together with the active viewport and appearance, while interaction indicators remain temporary presentation state.
